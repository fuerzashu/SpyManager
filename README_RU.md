\# SpyManager 🔎



\*\*Быстрый инструмент для проверки публичных профилей по имени пользователя.\*\*



SpyManager проверяет публичные URL-адреса профилей на нескольких платформах. В программе есть интерфейс командной строки, параллельные проверки и экспорт результатов в JSON и TXT.



> \*\*Важно:\*\* SpyManager предназначен для проверки общедоступных страниц профилей. Он не получает доступ к приватным аккаунтам, не обходит авторизацию и не гарантирует, что найденный профиль принадлежит конкретному человеку.

\## 📦 Установка



\*\*Требования:\*\* Python 3.10 или новее. Git нужен только для клонирования репозитория.



\### 1. Скачайте проект



Клонируйте репозиторий:



```bash

git clone https://github.com/fuerzashu/SpyManager.git

cd SpyManager

```



Или скачайте проект в формате ZIP и распакуйте архив.



\### 2. Установите зависимости



```bash

python -m pip install -r requirements.txt

```



Если команда `python` не работает, попробуйте `python3`.



\## 🚀 Использование



\### Проверить имя пользователя



```bash

python spymanager.py example --lang ru

```



\### Запустить английский интерфейс



```bash

python spymanager.py example --lang en

```



\### Посмотреть список платформ



```bash

python spymanager.py --sites

```



\### Сохранить результаты в файлы



```bash

python spymanager.py example --json results.json --txt results.txt

```



\### Посмотреть все доступные параметры



```bash

python spymanager.py --help

```



\## 📊 Как понимать результаты



SpyManager показывает результат проверки каждого публичного URL-адреса.



\- \*\*Найден / Возможное совпадение:\*\* страница может существовать; требуется ручная проверка.

\- \*\*Не найден:\*\* ответ платформы интерпретирован как отсутствие профиля.

\- \*\*Неизвестно / Ошибка:\*\* достоверно определить результат не удалось.



\*\*Важно:\*\* HTTP-коды и ответы сайтов не являются окончательным доказательством существования или отсутствия аккаунта. На результат могут влиять перенаправления, ограничения частоты запросов, блокировки доступа и изменения на стороне платформы.
